## Автор
Радыно Екатерина Александровна

## Назначение программы

Менеджер личных расходов — консольная программа на Python для учёта личных трат.

Программа позволяет:
- Добавлять расходы с указанием названия, категории и суммы.
- Просматривать список всех расходов.
- Рассчитывать общую сумму расходов.
- Просматривать статистику расходов по категориям.

## Требования

- Python 3

Дополнительные библиотеки не требуются.

## Как запустить

Откройте терминал в папке проекта и выполните команду:

    python main.py

## Проверка работы программы

### Проверка 1. Обычный сценарий

Ввод:
1. Добавить расход «Продукты», категория «Еда», сумма 500.
2. Добавить расход «Такси», категория «Транспорт», сумма 300.
3. Посмотреть общую сумму расходов.
4. Посмотреть статистику.

Ожидаемый результат:
- Еда — 500 руб.
- Транспорт — 300 руб.
- Общая сумма — 800 руб.

### Проверка 2. Необычный сценарий

Ввод:
1. Попытаться добавить расход с отрицательной суммой.
2. Попытаться добавить расход с текстом вместо числа.
3. Попытаться посмотреть расходы, если список пуст.

Ожидаемый результат:
- Отрицательная сумма не добавляется.
- При вводе текста вместо числа выводится сообщение об ошибке.
- При отсутствии расходов программа сообщает, что список пуст.

## Возможные улучшения

В дальнейшем можно добавить сохранение расходов в файл, редактирование и удаление записей.
